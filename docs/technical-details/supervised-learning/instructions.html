Supervised Learning

Overview

Supervised learning is a type of machine learning that aims to fit the best model for predicting values of a labeled variable. The purpose of performing supervised learning on this data is to determine whether movie profitability can be predicted using features available before release, and to understand which factors most strongly influence box office success.

I performed binary classification to predict whether films will be profitable (revenue exceeds budget) or unprofitable. Three classification algorithms were trained and compared: Logistic Regression, Random Forest, and Gradient Boosting. The model selection methods, evaluation metrics, and results are discussed in the sections below.

Below is an outline of general information applied to all models:

Data Preprocessing

In order to be used in supervised learning, data must be cleaned, processed, and standardized following specific criteria. The following techniques were performed on the data:

Feature Selection - I selected features available before a film’s release: budget, budget tier, cast popularity, primary genre, release season, release year, and runtime. Post-release metrics like vote average and vote count were excluded since they aren’t available during pre-production when investment decisions get made.

Target Variable - The binary profitable indicator served as the classification target, where 1 indicates revenue exceeded budget and 0 indicates the film lost money.

Handling Categorical Variables - Categorical variables (primary genre, budget tier, release season) were one-hot encoded to be represented as numerical variables and included in the supervised learning models. - What is one-hot encoding?: A machine learning technique that converts categorical data into numerical data, denoted as 0 or 1. The levels of the categorical variable are pivoted so that each level becomes a column. If the row satisfies the categorical variable level, a 1 is input under that level’s column, while the remaining levels fill with 0.

Standardization - The data was scaled using Scikit-learn’s StandardScaler, which applies z-score standardization to the data. This ensures all features contribute equally to model training regardless of their original scale.

Testing and Training Strategy

All models used an 80-20 training-testing split with stratified sampling to maintain class balance. The dataset was split using Scikit-learn’s train_test_split function, which randomly assigns 80% of the data to training and 20% to testing while preserving the proportion of profitable vs unprofitable films in both sets.

I used 5-fold cross-validation during training to assess model stability and reduce overfitting risk.

Model Selection

I trained three classification algorithms to compare their performance:

Logistic Regression - A linear model that predicts the probability of profitability using a logistic function. It serves as the baseline model and provides interpretable coefficients.

Random Forest - An ensemble method that builds multiple decision trees and aggregates their predictions. It handles non-linear relationships well and provides feature importance rankings.

Gradient Boosting - An ensemble method that builds trees sequentially, with each tree correcting errors from previous trees. It often achieves high accuracy but requires careful tuning.

Evaluation Metrics

Model performance was assessed using multiple classification metrics:

Accuracy - The percentage of correct predictions across all movies.

Precision - The proportion of movies predicted as profitable that actually were profitable. High precision means few false positives.

Recall - The proportion of actually profitable movies that were correctly identified. High recall means few false negatives.

F1-Score - The harmonic mean of precision and recall, balancing both metrics into a single score.

For this application, recall is more important than precision. Studios want to avoid passing on films that would succeed (false negatives) more than they want to avoid greenlighting films that will fail (false positives).
