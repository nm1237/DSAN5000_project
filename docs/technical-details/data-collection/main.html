Data Collection

Overview

Goals

The goal of this data collection phase was to gather comprehensive movie information from The Movie Database (TMDB) to analyze patterns in box office success. TMDB provides detailed financial data, cast information, production details, and temporal features needed for profitability analysis.

I targeted movies with complete budget and revenue information since these financial metrics are essential for the analysis. I only included movies with at least 100 user votes to ensure data quality. I queried the API systematically to retrieve popular films where both production costs and box office earnings are documented.

Motivation

Predicting box office success has challenged the film industry for decades. Studios invest hundreds of millions in productions with limited ability to forecast performance. Executives rely on star power, comparable film analysis, and gut instinct, but data-driven approaches may reveal patterns traditional methods miss.

Understanding what drives box office success has practical implications beyond just making studios money. When studios make better investment decisions, they can take more creative risks rather than churning out safe franchise sequels. For audiences, improved decision-making could mean more diverse films getting greenlit. For data science, this demonstrates how machine learning can extract meaningful patterns from complex domains where art intersects with commerce.

Objectives

The main objectives of this data collection phase were to:

  • Gather financial data (budget and revenue) for a large sample of theatrical releases
  • Collect cast and crew information to analyze the impact of talent on performance
  • Obtain genre classifications and temporal features to study market patterns
  • Ensure data quality by filtering for complete records and sufficient vote counts
  • Create a dataset suitable for exploratory analysis, clustering, and predictive modeling

By collecting this comprehensive data, I aimed to identify which factors most strongly predict profitability, whether different types of movies follow different patterns, and how release timing affects success rates.

Methods

Data Collection

All data used in this project comes from The Movie Database (TMDB) API. TMDB maintains one of the largest databases of movie information with reliable financial data, cast details, and production metadata. The API provides free access for research purposes with reasonable rate limits.

I used automated API queries with Python’s requests library to systematically retrieve movie lists and detailed information for each film, filtering for records with complete budget and revenue data.

API Selection

I selected TMDB for several reasons. The API provides comprehensive movie data including financial information that many other sources don’t make publicly available. TMDB’s data quality is reliable, maintained by a large community of contributors. The API documentation is clear and the rate limits are reasonable for academic research. Most importantly, TMDB includes both recent releases and historical films, enabling analysis across different eras of cinema.

Collection Approach

The collection process used two TMDB API endpoints. The /discover/movie endpoint retrieved lists of popular movies sorted by popularity with vote counts of at least 100. The /movie/{id} endpoint provided detailed information for each film including cast, crew, and financial data. I only retained movies with non-zero budget and revenue values since these are required for profitability analysis.

API Endpoints Used

Discovery Endpoint: /discover/movie - Sorted by popularity (sort_by='popularity.desc') - Filtered for vote count (vote_count.gte=100) - Retrieved paginated lists of movies

Details Endpoint: /movie/{id}
- Appended credits data (append_to_response='credits') - Retrieved comprehensive movie information including financials

Rate Limiting

I implemented a 0.25-second delay between requests to respect API rate limits and avoid overloading TMDB servers. This results in approximately 4 requests per second, well within acceptable usage. The collection process took several hours but ensured ethical API usage.

Features Collected

I extracted 18 features from API responses:

Financial Metrics: - Budget (production cost in USD) - Revenue (box office earnings in USD)

Cast and Crew: - Top 5 cast members by billing order - Average cast popularity (aggregated from individual actor popularity scores) - Director name

Production Details: - Up to 3 production companies
- All genres (pipe-separated string) - Primary genre (first listed)

Film Metadata: - Title, movie ID, release date - Runtime (minutes) - Vote average and vote count (user ratings from TMDB) - Popularity score (TMDB metric) - Overview text (first 500 characters)

Temporal Features: - Release year (extracted from release date) - Release month (extracted from release date)

Data Structure

I stored the collected data in tabular format with each row representing one movie and each column representing a feature. Multi-value fields like genres and cast were stored as pipe-separated strings (e.g., “Action|Adventure|Sci-Fi”) to maintain a flat table structure while preserving all information. This format facilitates easy loading into pandas DataFrames for subsequent analysis.

import requests
import pandas as pd
import time
from datetime import datetime
import os
from dotenv import load_dotenv

# ==========================================
# TMDB DATA COLLECTION SCRIPT
# ==========================================

# load environment variables from .env file
load_dotenv()

API_KEY = os.getenv("5d36ddb017b75e39993969f4f023d8cf")

BASE_URL = "https://api.themoviedb.org/3"

# output directory
OUTPUT_DIR = "../../data/raw-data"
os.makedirs(OUTPUT_DIR, exist_ok=True)

def get_popular_movies(page=1):
    """Get popular movies from TMDB"""
    url = f"{BASE_URL}/discover/movie"
    params = {
        'api_key': API_KEY,
        'language': 'en-US',
        'sort_by': 'popularity.desc',
        'include_adult': 'false',
        'include_video': 'false',
        'page': page,
        'vote_count.gte': 100  # only movies with at least 100 votes
    }
    response = requests.get(url, params=params)
    return response.json()

def get_movie_details(movie_id):
    """Get detailed information for a specific movie"""
    url = f"{BASE_URL}/movie/{movie_id}"
    params = {
        'api_key': API_KEY,
        'append_to_response': 'credits'  # include cast and crew
    }
    response = requests.get(url, params=params)
    return response.json()

def extract_movie_data(movie_details):
    """Extract relevant features from movie details"""
    
    # basic info
    movie_data = {
        'movie_id': movie_details.get('id'),
        'title': movie_details.get('title'),
        'release_date': movie_details.get('release_date'),
        'budget': movie_details.get('budget'),
        'revenue': movie_details.get('revenue'),
        'runtime': movie_details.get('runtime'),
        'vote_average': movie_details.get('vote_average'),
        'vote_count': movie_details.get('vote_count'),
        'popularity': movie_details.get('popularity'),
        'overview': movie_details.get('overview', '')[:500],  # first 500 chars
    }
    
    # extract genres
    genres = movie_details.get('genres', [])
    movie_data['genres'] = '|'.join([g['name'] for g in genres])
    movie_data['primary_genre'] = genres[0]['name'] if genres else None
    
    # extract production companies
    companies = movie_details.get('production_companies', [])
    movie_data['production_companies'] = '|'.join([c['name'] for c in companies[:3]])  # top 3
    
    # extract cast (top 5 actors)
    credits = movie_details.get('credits', {})
    cast = credits.get('cast', [])[:5]
    movie_data['cast'] = '|'.join([actor['name'] for actor in cast])
    movie_data['cast_popularity'] = sum([actor.get('popularity', 0) for actor in cast]) / len(cast) if cast else 0
    
    # extract director
    crew = credits.get('crew', [])
    directors = [person['name'] for person in crew if person['job'] == 'Director']
    movie_data['director'] = directors[0] if directors else None
    
    # extract release month and year
    if movie_data['release_date']:
        try:
            release_dt = datetime.strptime(movie_data['release_date'], '%Y-%m-%d')
            movie_data['release_year'] = release_dt.year
            movie_data['release_month'] = release_dt.month
        except:
            movie_data['release_year'] = None
            movie_data['release_month'] = None
    else:
        movie_data['release_year'] = None
        movie_data['release_month'] = None
    
    return movie_data

def collect_movies(num_pages=250):
    """
    Collect movies from TMDB
    Each page has ~20 movies, so 250 pages = ~5,000 movies
    """
    
    all_movies = []
    movies_collected = 0
    errors = 0
    
    print(f"Starting data collection...")
    print(f"Target: {num_pages} pages (~{num_pages * 20} movies)")
    print("=" * 60)
    
    start_time = time.time()
    
    for page in range(1, num_pages + 1):
        try:
            # get list of movies on this page
            popular_movies = get_popular_movies(page)
            movie_list = popular_movies.get('results', [])
            
            # get detailed info for each movie
            for movie in movie_list:
                try:
                    movie_id = movie['id']
                    details = get_movie_details(movie_id)
                    
                    # only keep movies with budget and revenue data
                    if details.get('budget', 0) > 0 and details.get('revenue', 0) > 0:
                        movie_data = extract_movie_data(details)
                        all_movies.append(movie_data)
                        movies_collected += 1
                    
                    time.sleep(0.25) 
                    
                except Exception as e:
                    errors += 1
                    print(f"Error processing movie ID {movie_id}: {str(e)}")
                    continue
            
            # progress update every 10 pages
            if page % 10 == 0:
                elapsed = time.time() - start_time
                rate = movies_collected / elapsed * 60  # movies per minute
                print(f"Page {page}/{num_pages} | Movies collected: {movies_collected} | "
                      f"Rate: {rate:.1f} movies/min | Errors: {errors}")
        
        except Exception as e:
            print(f"Error on page {page}: {str(e)}")
            errors += 1
            continue
    
    # final summary
    elapsed = time.time() - start_time
    print("=" * 60)
    print(f"Collection complete!")
    print(f"Total movies collected: {movies_collected}")
    print(f"Total errors: {errors}")
    print(f"Time elapsed: {elapsed/60:.1f} minutes")
    
    return all_movies

def main():
    """Main execution function"""
    
    # check API key
    if API_KEY == "YOUR_API_KEY_HERE":
        print("ERROR: Please replace 'YOUR_API_KEY_HERE' with your actual TMDB API key")
        return
    
    print("TMDB Movie Data Collection")
    print("=" * 60)
    
    # collect movies
    movies = collect_movies(num_pages=250)
    
    # convert to DataFrame
    df = pd.DataFrame(movies)
    
    # cave to CSV
    output_file = os.path.join(OUTPUT_DIR, 'tmdb_movies_raw.csv')
    df.to_csv(output_file, index=False)
    
    print(f"\nData saved to: {output_file}")
    print(f"Dataset shape: {df.shape[0]} movies × {df.shape[1]} features")
    print("\nColumn names:")
    print(df.columns.tolist())
    
    # quick data preview
    print("\nSample of collected data:")
    print(df[['title', 'budget', 'revenue', 'primary_genre', 'release_year']].head(10))

if __name__ == "__main__":
    main()

Challenges

The data collection process encountered a few technical challenges. API rate limiting required careful timing between requests to avoid hitting usage caps. Some movies had incomplete cast or crew information requiring error handling. The biggest challenge was determining appropriate filtering criteria. Including all movies regardless of data completeness would have produced a larger dataset but introduced significant missing values. Filtering strictly for complete budget and revenue data reduced the dataset size but ensured every record could be used for financial analysis.
